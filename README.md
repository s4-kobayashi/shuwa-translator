# 手話翻訳

Webカメラに映った手話をブラウザの中で読み取り、映像の上に字幕として表示するアプリです。読み取った内容は記録として残り、テキスト・表(CSV)・字幕(SRT)・JSON でダウンロードできます。字幕を焼き込んだ録画も保存できます。

**使う: https://s4-kobayashi.github.io/shuwa-translator/**

PC(Chrome / Edge / Safari)とスマホ(Android の Chrome、iPhone の Safari)で動きます。サーバーは不要で、GitHub Pages の URL を開くだけで使えます。カメラの映像は端末の中だけで処理され、外部には送信されません。

## 何が読めるか

- **指文字 46 字**: 静止形 41 字と、動きのある の・も・り・を・ん。字を出した後の動きで濁点(横)・半濁点(上)・小さい字(手前)・長音(下)を付けられます。
- **単語 20 語**: ありがとう、おはよう、こんにちは、こんばんは、ごめんなさい、よろしくお願いします、さようなら、大丈夫、好き、元気、会う、はじめまして、お疲れ様、わかる、何、私、あなた、名前、赤 など。おはよう・こんにちは のような 2 動作の言葉は、続けて表すと 1 語にまとまります。
- **自分で登録した手話**: 「辞書」タブで、字幕に出したい言葉を入力し、同じ手話を 3〜5 回カメラに見せると、次からその言葉で字幕になります。組込みと同じ名前で登録すると、登録した方が優先されます。辞書はファイルに書き出して別の端末で読み込めます。

組込み語彙の形の根拠(自治体の手話資料など)と、確認できずに外した語は [docs/vocabulary.md](docs/vocabulary.md) にまとめています。

## 使い方

1. ページを開いて「カメラを開始」を押し、カメラを許可します。頭から腰までと両手が映る距離(1〜1.5 m)が目安です。
2. 指文字は手の形を止めます。黄色い字と下線のゲージが出て、ゲージが満ちると白い字幕に確定します。同じ字を続けるときは、いったん手を下ろすか少し動かしてから形を作り直します。
3. 単語は動いたあと手を一瞬止めると読み取ります。
4. 手を 2 秒ほど下ろすと改行します。間違えたら「1つ戻す」、記録の各行は「直す」「消す」で修正できます。
5. 「記録」タブからダウンロードします。「録画」を押すと字幕入りの映像を録画し、停止後に保存できます。録画中はこのタブを前面に出しておいてください(裏に回すとブラウザが描画を間引き、映像がカクつきます)。音声は録音しません。

「設定」では利き手(左利きは左手)、指文字だけ/単語だけの切り替え、確定までの時間、読み取りの積極さ(低いほど自信のあるときだけ字幕にする)を変えられます。記録・辞書・設定はこの端末のブラウザに保存されます。

## 精度について(正直な現状)

このアプリは学習済みの「手話翻訳 AI」ではありません。日本手話について自由に再配布できる学習データ・学習済みモデルが見つからなかったため、MediaPipe が検出した手の 21 点と体の位置から、手の形・向き・位置・動きを規則で判定しています。精度を上げる工夫は次の 4 つです。

- 自信がない読み取りは字幕にしない(棄却)。上位候補と信頼度は映像の右上に常に表示します。
- 形を一定時間止めて初めて確定する(ゲージ)ので、手の移り変わりの途中の形は出ません。
- 自分の手話を見本として登録すると、その人の表し方で照合します(少数サンプル学習)。
- 記録はあとから手で直せます。

テストで測った数値(`npm test`):

| 項目                                                                  | 結果                                         |
| --------------------------------------------------------------------- | -------------------------------------------- |
| 実写写真 4 枚(MediaPipe の実出力)の指文字                             | 4/4 正解、2 位との差 0.3 以上                |
| 合成した手(±15° の回転、±20% の大きさ、3% のノイズ)の指文字 41 字     | 右手 98.7%、左手 98.5%                       |
| 指が半端に曲がった手(どの字でもない形)を誤って受理                    | 6/400                                        |
| 単語 20 語・動く指文字 5 字・付加の動き 4 種(合成、速さ 0.75〜1.3 倍) | すべて 1 位                                  |
| 登録した手話(見本 3 回)の認識                                         | 形 92.5%、動き 100%、未登録の手話の誤受理 0% |

**実際の手話者による精度はまだ測っていません。** 上の数値は、資料の記述どおりに作った合成データと少数の写真によるものです。手の形が隠れる角度、暗い部屋、速い動き、地域や人による表し方の違いでは読み違えます。表情や文法を含む文の翻訳には対応していません。読めない手話は辞書に登録して補ってください。

手話の動画があれば、公開版と同じ処理での正解率を測れます。動画と正解を `manifest.json` に書き(`[{"file": "a.mp4", "expect": "ありがとう"}]`、語彙外の手話は `"expect": ""`)、次を実行します。完全一致の数、文字誤り率、語彙外の手話を出さずに済んだ数を表示します。動画は端末内で変換するだけで、どこにも送りません(ffmpeg が必要)。

```bash
node tests/e2e/eval-video.mjs path/to/manifest.json --out result.json
```

## GitHub Pages で公開する

1. このフォルダを GitHub のリポジトリにプッシュします(`vendor/` も含めます。合計約 35 MB、最大のファイルは 11 MB)。
2. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。

カメラは https のページでしか使えませんが、GitHub Pages は https で配信されます。パスはすべて相対なので、リポジトリ名は何でも動きます。`.nojekyll` は Jekyll の処理を止めるためのファイルです。

## 開発

必要なもの: Node.js 20 以上、[uv](https://docs.astral.sh/uv/)(開発用サーバー)。

```bash
npm install
```

```bash
npm test
```

```bash
uv run scripts/serve.py 8099 .
```

ブラウザで http://127.0.0.1:8099/ を開きます(localhost はカメラを使えます)。`python -m http.server` は Windows で `.js` を誤った MIME 型で返し、モジュールが読み込めないことがあるため使いません。

ブラウザでの通しテスト(Edge または Chrome を偽のカメラで起動し、字幕・ダウンロード・録画・辞書登録・保存を確認します)。`--prefix` を付けると GitHub Pages と同じサブパスで配信して確認します。

```bash
node tests/e2e/run.mjs --prefix shuwa
```

公開中のサイトをそのまま確認するときは `--url` を付けます。

```bash
node tests/e2e/run.mjs --url https://s4-kobayashi.github.io/shuwa-translator/
```

URL に `?test=1` を付けると、テスト用に `window.__shuwa`(合成した特徴量を流し込む口と状態の読み出し)が有効になります。通常の利用には影響しません。

MediaPipe の取得し直し(`vendor/` を作り直し、ハッシュを `vendor/mediapipe/CHECKSUMS.txt` に記録します):

```bash
npm run vendor
```

### 構成

| ファイル                                  | 役割                                           |
| ----------------------------------------- | ---------------------------------------------- |
| `index.html`, `css/app.css`, `js/main.js` | 画面と配線                                     |
| `js/camera.js`, `js/detector.js`          | カメラ、MediaPipe(手 2 つ + 姿勢)              |
| `js/features.js`                          | 手の形・向き・体を基準にした位置の特徴量       |
| `js/handshape.js`                         | 指文字の手形判定                               |
| `js/signs.js`                             | 単語・動く指文字・付加の動きの規則             |
| `js/dtw.js`                               | 登録した手話との照合(k 近傍・DTW)              |
| `js/recognizer.js`                        | 止め/動きの区切り、確定ゲージ、棄却            |
| `js/transcript.js`                        | 記録と TXT/CSV/SRT/JSON 書き出し               |
| `js/storage.js`, `js/recorder.js`         | 端末内保存(IndexedDB)、字幕入り録画            |
| `tests/`                                  | 単体テスト、合成の手モデル、ブラウザ通しテスト |
| `docs/`                                   | 語彙の出典、計画、設計判断の記録(ADR)          |
