# 組込み語彙と出典

このシステムが「学習なしで」読み取る手話の一覧と、その形の根拠です。ここにない手話は、アプリの「辞書」画面で自分の手話を 3〜5 回見せて登録すれば認識できるようになります。組込み語彙も、同じ名前で登録すれば登録した見本が優先されます。

確度の記号: **A** = 公的資料・百科事典の文章で手形・位置・動きを確認 / **B** = 検索結果の抜粋で確認、または一般的な指差し表現で原資料の全文は未確認。

## 指文字(46 字+付加の動き)

手のひらは原則「見る人(カメラ)に向ける」(W 冒頭の記述)。「横」は手の甲側の向きにかかわらず水平方向。右手の記述で、左利き設定では左右を反転して照合します。
