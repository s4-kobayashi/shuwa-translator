# ADR 0003: 左右の判定と、動きの区切り方

- 日付: 2026-11-18
- 状態: 採用

## 左右(handedness)

MediaPipe の文書は鏡像入力を前提とするが、tasks-vision 0.10.35 に鏡像にしていないカメラ画像を渡して実写写真で測ったところ、ラベルは本人の解剖学的な手("Right" = 本人の右手)だった。`js/features.js#anatomicalSide` はラベルをそのまま使い、2 つの手が同じラベルになったときだけ画像上の位置で決める。測定は `tests/features.test.mjs` に固定してある。画面表示だけを CSS で鏡像にし、認識には影響させない。

## 動きの区切り

「動き」の量は、直近 3 フレームの平均と約 130 ms 前の 3 フレームの平均の差(平面の移動 + 手の大きさの変化 × 1.5 + 指の伸びの変化 × 0.3、小さな揺れは不感帯で無視)とし、0.38 肩幅/秒を 3 フレーム続けて超えたら動作の開始とする。

検討した案:

- 1 フレームごとの速度(当初の実装)— 合成の揺れ(3° 回転、2% のノイズ)で動作と誤判定し、同じ字が二重に確定した。
- 平面の移動だけ — 前に出す(良い・お願い)、手前に引く(小さい字)、指を曲げるだけ(挨拶・も)を検出できなかった。

棄却された動作区間は「手の移り変わり」とみなし、手が実際に 0.12 肩幅以上動いたか形が変わったときだけ再び確定できるようにする(揺れで同じ字が繰り返されないため)。区間の終わりの静止時間は次の字の確定ゲージに加算する。
