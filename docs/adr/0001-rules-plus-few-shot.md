# ADR 0001: 規則ベースの組込み語彙 + 利用者の少数サンプル登録

- 日付: 2026-11-18
- 状態: 採用

## 背景

日本手話について、自由に再配布できる学習済みモデルやランドマークの学習データが見つからなかった(ub-MOJI は非商用・再配布禁止、JSL-DC は公開未確認)。静的サイトで URL を開くだけで動き、映像を端末外に出さないことが要件。

## 検討した案

| 案                              | 評価                                                              |
| ------------------------------- | ----------------------------------------------------------------- |
| A 規則だけ                      | 設定なしで動くが、個人差に弱い                                    |
| B 少数サンプル学習だけ          | 登録した人には高精度だが、最初は何も読めない                      |
| C クラウドの画像対応 LLM に送る | 映像が外部に出る、API キーが静的ページで露出、遅延と費用 → 不採用 |
| D ASL の学習済みモデルを流用    | 言語が違う → 不採用                                               |

## 決定

A + B。MediaPipe の手 21 点と姿勢から作った特徴量に対し、資料の記述から書いた規則(指文字 46 字・単語 20 語)で判定し、利用者が登録した見本(静止形は k 近傍、動きは DTW)を同名の組込みより優先する。自信がない出力は棄却し、確定前の候補と信頼度を表示する。

## 可逆性

可逆。認識は `js/recognizer.js` の候補リストに集約されているので、将来公開データが出れば学習済み分類器を候補の 1 つとして追加できる。

## 3 か月後の失敗シナリオ

実際の手話者の手で特徴量の分布が合成データとずれ、特定の字(え・こ・ほ など曲げの度合いで分ける字)が読めない。→ 対策: 確定ゲージと信頼度表示で誤りが見え、辞書登録で個人の形に合わせられる。実測データが集まったら `js/handshape.js` の閾値を調整する。
